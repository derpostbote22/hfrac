# H-frac Index Calculator

A lightweight [Streamlit](https://streamlit.io/) web application that calculates a researcher's fractional h-index (h-frac) dynamically. By dividing citations by the number of authors per paper, the h-frac index offers a normalised view of a researcher's impact. 

The app pulls real-time publication and citation data using the [OpenAlex API](https://openalex.org/). It can be accessed [here](https://h-frac.streamlit.app).
